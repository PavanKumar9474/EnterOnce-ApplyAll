# ApplyOnce

**ApplyOnce** is a universal career website autofill Chrome extension designed to streamline and automate job application submissions across multiple platforms.

---

## Project Structure

- **`frontend/`**: React + Vite web application for profile configuration, application tracking, and user settings.
- **`backend/`**: Python FastAPI backend service handling data processing, parsing, and integrations.
- **`extension/`**: Chrome Manifest V3 browser extension responsible for detecting form fields and autofilling application details across job boards and career portals.
- **`automation/`**: n8n workflows and pipeline definitions for webhook automations, alerts, and synchronization.
